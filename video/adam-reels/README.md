# «Адам»: вертикальный ролик

31 секунда, 1080 × 1920, 30 кадров/с. Русский синтезированный диктор, вшитые субтитры, реальные опубликованные упражнения сайта, музыка и эффекты. Сцены: Ӕ и акварель сайта → название, плавный выбор слов в аудиопазле, ввод и серверная проверка кроссворда, переворот клеток «Пяти букв», цветные карточки форматов и финал.

## Подготовка

Видеопроект независим от ASP.NET. Зависимости и медиа не входят в Git. После `npm ci` выполните `node capture.cjs` при запущенной актуальной `dev`. Локальный адрес задаётся через `ADAM_TEST_URL`; по умолчанию `http://127.0.0.1:58440`. Подключение сайта загружается из `.run-local/connection.ps1` согласно основному README. Скрипт работает гостем, использует только опубликованные материалы и не записывает личный прогресс. Нельзя подменять отсутствующие учебные данные выдуманным текстом. При повторной съёмке проверьте соответствие зафиксированного слова дня в сцене Wordle и `public/layout.json`.

После основной съёмки выполните `node capture-audio.cjs`: он сохраняет реальные кнопки и выбранные слова отдельно при масштабе 3×, а также `audio-choices.json`. Анимация использует исходные плитки, скрывает выбранный экземпляр до перелёта и помещает его в точное место ответа. Первая пара вариантов плавно исчезает перед появлением следующей. Используются два выбора без выдуманного перевода.

В `public/fonts/` нужны Onest и Golos Text из `IronLanguage.Web/wwwroot/fonts/`. В `public/audio/`: `narration.mp3` (образец в `.run-local/adam-reels/`), `music.mp3`, `sweep.mp3`, `tap.mp3`, `impact.mp3` из перечисленных ниже источников. Для оформления: `watercolor.png` из `images/green/kurt-tag-watercolor.png`, `brand.svg` из `images/adam-mark.svg`, `family.webp` из `images/crosswords/family-v1.webp`. Пути изображений указаны относительно `IronLanguage.Web/wwwroot/`. `public/` содержит локальные снимки и лицензии и целиком игнорируется.

## Проверка и рендер

Из этой папки:

```powershell
.\node_modules\.bin\tsc.cmd
node --check capture.cjs
npm run render -- --browser-executable="C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --concurrency=3 --codec=h264 --crf=18 --pixel-format=yuv420p --audio-codec=aac
```

Для версии без музыки передайте файл свойств с `{"bgm":false}` через `--props=<путь>`. Речь и эффекты сохраняются. Обе версии используют `src/timeline.ts`; в нём же хранятся субтитры и звуковые события. `src/workbench.ts` описывает сцены и титры для монтажной панели скилла. В текущей Windows её штатный запуск не удался: создание символической ссылки возвращает `EPERM`. Сам MP4 от этого не зависит. Исходники доступны через Remotion Studio (`npm run studio`). Полная эквивалентность импорта в панель не проверена.

Актуальные локальные файлы: `out/adam-reels-final.mp4`, `out/adam-reels-no-music-final.mp4`, `out/adam-reels-final.srt`. Более ранние экспорты сохранены отдельно. Последняя сцена аудиопазла переснята без hover/focus и перерендерена кадрами 150–269. `finalize.py` собирает полный ролик с этой сценой и нетронутыми звуковыми дорожками соответствующих версий v3. Повторный полный Remotion render из актуального кода воспроизводит тот же монтаж. Кадры проверки и независимый отчёт находятся в `out/qa/`. Публикация в соцсетях не выполнялась. Адрес сайта для финала не задан, поэтому выдуманная ссылка не используется.
