- Golos Text: https://github.com/google/fonts/tree/main/ofl/golostext — вариативный оригинальный TTF, веса 400–900.

Файлы загружены из официального репозитория Google Fonts 8 октября 2026 года без модификации или сокращения набора символов. Лицензии и авторские сведения находятся в OFL.txt рядом с каждым файлом. Оба файла содержат кириллицу и осетинские Ӕ/ӕ. Подключение выполняется через @font-face с font-display: swap; Onest предзагружается в общем шаблоне.
