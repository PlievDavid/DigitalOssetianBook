# Иллюстрации карточек кроссвордов

Десять декоративных PNG для каталога `/games/crosswords`. Подготовлены 18 октября 2026 года встроенным инструментом OpenAI `image_gen` по одобренному пользователем макету платформы «Адам». Каждый рисунок извлечён отдельным запросом с `transparent_background: true`; текст, интерфейс и звёзды в PNG не входят. Светлое органическое пятно является частью рисунка, пространство вокруг него прозрачно.

Файлы квадратные, 1254 × 1254 px: это исходный размер результата генератора с запасом для экранов высокой плотности. Их следует показывать через `object-fit: contain`, без растягивания и обрезки. Иллюстрации декоративные: название темы уже есть в карточке, поэтому у изображения используется пустой `alt`.

## Набор и промпты

Общая инструкция для всех запросов: «Извлечь только указанный тематический рисунок из одобренного макета; максимально сохранить композицию, формы, персонажей, цвета и мягкую рисованную стилистику. Удалить все надписи, цифры, звёзды, рамки, прямоугольный фон карточки и соседние изображения. Оставить небольшое органическое пятно и связанные с рисунком листья. Отцентрировать на квадратном холсте с небольшими прозрачными полями. Фон вне рисунка — настоящий alpha, не белая заливка и не нарисованная шахматная сетка».

Фотография не включена в этот каталог; права на исходную фотографию здесь не утверждаются.

Это генеративное восстановление отдельных рисунков из макета, а не побитовая нарезка исходного скриншота. При замене сохраняйте версионированные имена, чтобы не смешивать кэш старых и новых изображений.
