# Восемь произведений для чтения

`drafts.json` — согласованная до обсуждения прав подборка восьми оригинальных стихотворений Коста: «Школьник», «Шалун», «Завещание», «Раздумье», «Надежда», «Желание», «Прощай!», «Мать сирот».

## Текущая подборка

27 октября 2026 года по просьбе пользователя в каталоге подготовленной локальной БД оставлены три произведения:

- «Школьник» (`schoolboy`) — простой диалог о школе и чтении.
- «Шалун» (`mischief`) — короткие обращения к животным; сохранены буквальные названия животных вместо замен ради рифмы.
- «Завещание» (`testament`) — восемь строк о песне и долге перед людьми.

Выбор отражает сравнительную уверенность в собственных подстрочниках после повторной сверки с [оригиналами](https://hetagurov.ru/po_kosta/perevody/if/ir_ru/) и словарём проекта, а не подтверждение профессиональной редакторской проверки. Переводы не менялись и не отмечались проверенными. Остальные пять записей архивированы штатным редактором: их тексты, главы, иллюстрации и позиции чтения сохранены, восстановление доступно в редакторе. Пользовательские черновики не затрагивались. Исходный JSON остаётся архивом всех восьми материалов; повторный импорт существующих ID не восстанавливает архивированные записи.

Русский текст — непроверенный рабочий перевод ИИ по запросу пользователя. Это не готовый учебный перевод и не тексты переводчиков исходного сайта. Символом ⚠ отмечены наиболее сомнительные интерпретации; остальные строки также требуют проверки специалистом по иронскому. Автор оригиналов — Коста Хетагуров. Источник каждого оригинала указан в `sourceUrl`, но внешняя ссылка в читалке не выводится.

Латинские типографские æ/Æ приведены к кириллическим ӕ/Ӕ. Слова, пунктуация и строфы не исправлялись. Перевод имеет то же число строк и пустых строк, что и оригинал. При выводе слова и пробельные фрагменты не разделяются дополнительными HTML-пробелами.

## Перенос

Публичный раздел — `/reading`, вместо прежних «Книг». `/books` перенаправляет в него. Модель книг и совместимый API сохранены для позиций и словаря. `reading-import --replace-library` применяет миграции и выполняет однократный транзакционный перенос в подготовленной БД: добавляет 8 произведений со стабильными ID, прежние опубликованные записи архивирует без удаления глав и позиций. Повторный импорт не перезаписывает новую редакторскую версию и сохраняет состояние архива. До импорта проверяется наличие восьми внутренних рисунков. Эта команда не применяет текущий отбор трёх произведений на новой пустой базе; после первоначального импорта нужно архивировать пять отложенных записей через редактор.

Необязательные переводы сохраняются в `BookChapter.Translation`; прежние общие поля оставлены для совместимости. В API и читалке непроверенный перевод видит только роль Editor. После проверки редактор публикует новую версию с общей отметкой `TranslationReviewed`; переводить все главы необязательно. Строки с ⚠ нельзя отметить проверенными. Исходный JSON вне wwwroot, прямой запрос получает 404. `/editor/reading-preview` остаётся закрытым предпросмотром всех восьми исходных черновиков и не меняет БД.

## Изображения

Готовы все 8 обложек и 8 отдельных внутренних иллюстраций в `wwwroot/images/reading`. Это отдельные файлы встроенного image_gen, не вырезки из макета. После временного HTTP 403 генерация продолжена 19 октября 2026. Обложка «Матери сирот» приведена к общей стилистике и исправлена по замечанию о пальцах. CLI/API-режим не использовался. Полные промпты и имена исходных файлов: `docs/design/reading-approved/images.json`.

`illustrationAfterLine` — число строк перед рисунком с учётом пустых строк, 0 — перед текстом. В обычном редакторе можно загрузить отдельный рисунок PNG/JPEG/WebP до 5 МБ, выбрать главу, номер строки и описание; существующий рисунок можно переместить или убрать в новой версии. Обложка собирается конструктором из текста, цветов, шрифта и принта; прежние файлы обложек сохранены как исходные материалы и не выводятся.

Проверка структуры: `dotnet run --project tests/ReadingChecks`. С подготовленной импортированной БД: `dotnet run --project tests/ReadingChecks -- --database`. Тест черновика откатывается транзакцией. Механическое совпадение строк не подтверждает лингвистическую точность перевода.
