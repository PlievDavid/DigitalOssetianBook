# Черновики чтения

`drafts.json` — согласованная до обсуждения прав подборка восьми оригинальных стихотворений Коста: «Школьник», «Шалун», «Завещание», «Раздумье», «Надежда», «Желание», «Прощай!», «Мать сирот».

Русский текст — непроверенный рабочий перевод ИИ для проверки пользователем. Это не опубликованные учебные переводы и не тексты переводчиков, перечисленных на исходном сайте. Символом ⚠ отмечены наиболее сомнительные интерпретации; остальные строки также требуют проверки специалистом по иронскому. Авторство исходных стихотворений: Коста Хетагуров. Источник каждого оригинала указан в `sourceUrl`.

Латинские типографские æ/Æ приведены к кириллическим ӕ/Ӕ. Слова, пунктуация и строфы не исправлялись. Перевод имеет то же число строк и пустых строк, что и оригинал. При выводе слова и пробельные фрагменты не разделяются дополнительными HTML-пробелами.

Предпросмотр доступен только роли Editor: `/editor/reading-preview`, также по ссылке на странице материалов. Он не читает и не изменяет записи книг, главы, позиции чтения или личный словарь. В `/books` черновики не появляются. JSON находится вне wwwroot и передаётся только в авторизованном ответе с запретом кеширования.

Обложки и иллюстрации внутри — отдельные изображения. Семь обложек сохранены в `wwwroot/images/reading`. Остальные девять изображений пока отсутствуют: встроенный генератор вернул ошибку доступа HTTP 403. Они не подменяются обложками или вырезками из макета. На их местах показаны явные текстовые заглушки; браузер не запрашивает отсутствующие файлы. Промпты и состояние: `docs/design/reading-approved/images.json`. Резервный CLI/API-режим требует OPENAI_API_KEY и отдельного согласия пользователя; он не использовался.

`illustrationAfterLine` — позиция иллюстрации в массиве строк (с учётом пустых). После добавления файла с указанным именем достаточно перезагрузить предпросмотр; менять данные БД не требуется.

Проверка структуры: `dotnet run --project tests/ReadingChecks`. Построчное соответствие проверяется механически; это не проверка лингвистической точности перевода.

До публикации: проверить и исправить переводы, завершить иллюстрации, отдельно реализовать сохранение рисунков через редактор и согласовать замену опубликованной библиотеки с сохранением пользовательских позиций. Старые книги сейчас не удалены и не архивированы.
