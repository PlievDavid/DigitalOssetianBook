# Кроссворды

`levels.json` — опубликованные фиксированные сетки. Подсказки — существительные из `../ossetian-russian-dictionary.csv`, ответы — только иронская колонка `ир1`. `sourceRow` — номер записи CSV, считая заголовки с 1; `sourceColumn` — индекс колонки, начиная с 0. Ударение убрано, латинское æ заменено на ӕ. Для ореха сохранено уточнение «грецкий».

Десять тем, 4–8 слов. Последняя тема объединяет одежду и дом: это позволяет получить связную сетку без неподтверждённых переводов. Сочетания букв (например, хъ) занимают отдельные клетки; ӕ — одну.

Уровни не меняются случайно при открытии. Публикация происходит вместе с кодом, конструктора кроссвордов в редакторе пока нет. При изменении опубликованного уровня **добавляйте** объект с тем же `id` и увеличенным `version`, сохраняя прежний объект и его сетку. Каталог показывает последнюю версию; уже открытое поле проверяется по своему номеру версии. Прогресс разных версий хранится раздельно. Не меняйте ответы, координаты или ID слов существующей версии.

`node scripts/generate-crosswords.cjs` из корня воспроизводит исходный набор v1. Это инструмент подготовки материала; не запускайте его поверх отредактированного опубликованного набора. Итоговые сетки и соответствие словарю проверяет `tests/CrosswordChecks`.
