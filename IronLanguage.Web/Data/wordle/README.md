# Слова для игры «Пять букв»

[Список всех 300 ответов с русскими заголовками](../../../docs/wordle-words.md).

`words.json` — опубликованный набор v1. В нём **300 разных ответов по пять букв**, преимущественно существительные, также общеупотребительные прилагательные. Исходник — предоставленный проекту `../ossetian-russian-dictionary.csv`, иронская колонка `ир1`. Для каждой записи сохранены русский заголовок, примечание, `sourceRow` (запись CSV, считая два заголовка с 1) и `sourceColumn` (индекс колонки с 0). Удалены ударения, латинское æ заменено на ӕ. Переводы не генерировались.

В `allowed` входят 519 разных однословных пятибуквенных форм той же колонки: они допускаются как попытки, включая глаголы и другие части речи. Набор ответов уже: исключены глаголы, служебные слова и часть редкой лексики. Одинаковые буквы засчитываются с учётом их количества в ответе. Буквы `ъ` и `ь` занимают самостоятельные клетки, `ӕ` — одну.

Порядок ответов зафиксирован: исходные 300 записей отсортированы по SHA-256 от `adam-wordle-v1:<слово>`. С 16 октября 2026 года используется индекс `(число дней от startDate) mod 300`. Через 300 дней цикл повторяется. День меняется в 00:00 UTC, одинаково для всех пользователей. **Не переставлять и не менять опубликованный набор в течение цикла.** Для изменения отбора нужен новый набор с явной будущей датой начала; не подменять список на лету. Первая принятая попытка сохраняет снимок ответа и перевода на день в БД; начатые игры используют этот снимок.

## Перенос на другую базу

После завершения своей игры вошедший пользователь может добавить раскрытый ответ в личный словарь кнопкой «В мой словарь». Сохраняется точное значение исходного словаря по `sourceRow`/`sourceColumn` с проверкой написания; для этой функции словарь должен быть импортирован в БД. Повторное сохранение не создаёт дубликат. Незавершённая или чужая партия не позволяет сохранить ответ. Сохранение уже раскрытого слова доступно и после смены дня UTC.

Файл `words.json` включён в Git и автоматически копируется в сборку и публикацию сайта (`Data/wordle/words.json`). Пять букв читает его напрямую и не зависит от импорта таблиц `DictionarySenses`. Для пустой подготовленной БД настройте `ConnectionStrings__Adam` и примените миграции EF Core, включая `DailyWordle`, по `docs/DEVELOPMENT.md`. Отдельного SQL-сида или импорта 300 слов не требуется. Список и порядок дней будут такими же на любом экземпляре сайта.

В БД находятся только дневные игры пользователей, снимки их ответов, статистика и общая активность. Если нужно сохранить существующие результаты при переезде, переносите данные БД обычным резервным копированием вместе с пользователями; развёртывание пустой БД их не восстанавливает.

JSON не раздаётся как статический ресурс и не отправляется клиенту. API возвращает правильное слово только после победы или шестой принятой попытки. Неизвестное слово, повтор той же попытки и ошибки формата не расходуют попытки. Гостевая игра хранится в существующем ограниченном кэше гостевых занятий (30 минут бездействия, максимум 2 часа, возможное вытеснение); смена cookie или истечение кэша начинает новую гостевую игру. Личная статистика и серия доступны только после входа.

Проверка источников, правил и расписания: `dotnet run --project tests/WordleChecks`. С подготовленной базой после загрузки `.run-local/connection.ps1`: добавьте `-- --database`. Если задан `ADAM_TEST_URL`, проверка также выполняет настоящий вход через HTTP, восстановление игры, повторный ответ и CSRF; временные учётные записи создаются с одноразовыми данными в памяти и удаляются в `finally`.
