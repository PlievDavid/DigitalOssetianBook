# Рабочий предпросмотр чтения

Ветка: `codex/books-library-mockup`. Маршрут: `/editor/reading-preview`, только роль Editor. Ссылка добавлена на страницу материалов. Это первая стадия переноса одобренного оформления, а не опубликованная новая библиотека.

Восемь отдельных карточек произведений; в читалке — оригинал и непроверенный перевод по строкам, строфы, пометки ⚠ и замечания для проверки. На узком экране переключаются языки; размер текста — 16–28 px. Место отдельного рисунка находится между строфами. Обложка не используется вместо рисунка внутри.

Сохранены четыре ранее созданные обложки и дополнительно сгенерированы три. Встроенный image_gen затем вернул HTTP 403, поэтому обложка «Матери сирот» и восемь внутренних рисунков отсутствуют. Заглушки обозначают это явно, не запрашивают несуществующие файлы и не выдаются за готовую графику. Файлы и промпты перечислены в `images.json`.

Данные и источники: `IronLanguage.Web/Data/reading/drafts.json` и соседний README. Сохранение рисунков в обычном редакторе, публикация, замена старых книг и перенос данных ещё не выполнены.

## Проверено 18 октября 2026

- `dotnet build IronLanguage.slnx --no-restore -v:quiet`: без ошибок и предупреждений.
- `dotnet run --project tests/ReadingChecks --no-restore`: проверка состава, 214 строк оригинала, числа и позиций переносов, путей, JSON-экранирования и ограничений доступа.
- `node --check IronLanguage.Web/wwwroot/js/reading-preview.js`: без ошибок.
- Живой сайт с подготовленной локальной БД: гость получает 302 на вход; прямой запрос `/Data/reading/drafts.json` получает 404. Вошедший редактор открывает предпросмотр.
- В браузере проверены все восемь произведений при ширине 1280: оригинал и перевод побуквенно совпадают с JSON, для каждого есть одно место под отдельный рисунок, футер сохранён.
- Ширины 320, 390, 768 и 1280: переключение языков, текст 28 px, открытие словарной подсказки клавишей Enter и закрытие Escape; горизонтального переполнения и битых изображений нет. Временный размер окна сброшен.

Эти проверки не подтверждают лингвистическую точность черновых переводов. Особенно отмеченные строки требуют проверки носителем/редактором. Книги, главы, пользовательские позиции и личный словарь в БД не менялись.
