# Чтение в стиле платформы

Файлы поставляются в WebP (качество 90, исходные размеры и композиция сохранены). В `images.json` поле `file` указывает текущий WebP, `sourceFile` сохраняет имя исходного результата генератора. Прежние PNG-адреса в опубликованных книгах перенаправляются на соответствующий WebP.

Ветка: `codex/books-library-mockup`. Основной раздел: `/reading`, заменяет «Книги». Все 8 обложек и 8 отдельных внутренних иллюстраций готовы и перенесены в приложение. Промпты, исходные файлы и происхождение — `images.json`; тексты и источники — `IronLanguage.Web/Data/reading`.

Карточка открывает текст сразу. На компьютере оригинал и перевод рядом без переключателя; на узком экране язык выбирается кнопками. Размер текста меняется. Рисунки размещены внутри произведений, показываются в собственных пропорциях без пустых боковых полос и обрезки. Корень страницы использует общий `feature-shell`, возврат и футер сохранены. Ссылки на оригиналы убраны из интерфейса.

Прежние две опубликованные книги в локальной БД перенесены в архив. Главы и пользовательские позиции не удалены. У восьми новых оригиналов стабильные ID. Переводы ИИ пока видит только редактор; проверку пользователем они не прошли. Редактор поддерживает отдельные рисунки, позицию, описание и проверку перевода через обычную новую версию.

## Проверки 19 октября 2026

- Сборка решения без предупреждений и ошибок; модель и снимок согласованы.
- 95 проверок данных, токенизации, стабильных ID, иллюстраций, идемпотентности импорта и сохранения черновика в откатываемой транзакции.
- Синтаксис `reading.js`, `reading-preview.js`, `editor.js`.
- Гостевой API: все 8 оригиналов доступны, черновые переводы пусты, 1 внутренняя иллюстрация у каждого; прямой JSON — 404, запись позиции без входа — 401, старый адрес — 302 в /reading.
- Живой браузер на компьютере: все 8 оригиналов и переводов побуквенно совпадают с исходным JSON, по одному рисунку, внешней ссылки нет, горизонтального переполнения нет.
- Проверен общий верхний отступ 32 px, отсутствие переключателя на компьютере, увеличение текста и возврат клавишей Enter. В форме файл выбран через file chooser: предпросмотр виден, часть выбрана, перевод по умолчанию не отмечен проверенным; тестовый материал не сохранялся.
- Ограничение текущего браузерного инструмента: попытка установить 390 × 844 не изменила фактическое окно (осталось 1280 × 720), поэтому мобильная ручная проверка этой версии не считается выполненной.

Эти проверки не подтверждают лингвистическую точность переводов. Полный сценарий загрузки файла, публикации и следующей версии в UI ещё требует отдельной проверки; сохранение метаданных рисунка и статуса перевода проверено с БД.
