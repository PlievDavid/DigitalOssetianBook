# Общее представление о системе
## Концепт
Планируется создать платформу наподобие [PuzzleEnglish](https://puzzle-english.com/) для изучения осетинского языка со своими уникальными типами заданий.

<img width="1889" height="844" alt="image" src="https://github.com/user-attachments/assets/5e72d863-f3dd-4132-acd4-c70ffa0d1db4" />

Вкладка "Задания" будет включать в себя модули с нашими уникальными тренажерами

<img width="600" height="393" alt="image" src="https://github.com/user-attachments/assets/4d628205-af9b-4e7b-861d-5ebf14713255" />

Вкладка "Курсы" будет содержать авторские курсы от преподавателей языка.
## Первостепенная задача
Реализовать вкладку "Задачи" и сделать для нее несколько модулей уникальных упражнений. Виды реализуемых упражнений выбираем из Issues.
