# Контекст работы над «Адам»

Актуально на 3 октября 2026 года. Это сводка для продолжения разработки; инструкции по запуску находятся в [README.md](README.md).

## Принятые решения

«Адам» — адаптивный сайт для изучения иронского варианта осетинского языка на ASP.NET Core MVC и .NET 10. В решении два проекта: `IronLanguage.Web` (страницы, контроллеры, правила занятий) и `IronLanguage.Db` (PostgreSQL, EF Core, миграции, интерфейсы и реализации репозиториев). Для доступа к данным используется название «репозиторий» (`I…Repository`, `Ef…Repository`). Первая версия бесплатна и требует интернета; Flutter в неё не входит.

Сейчас развиваются аудиопазлы, перевод фраз, личный словарь, чтение книг, повторение слов, игра на подбор пар, очки, награды и серии дней. Курсы, видеопазлы, диалоги, подкасты, личный план и подписка отложены. Подключение полного осетинско-русского словаря пользователь пока отложил; машинный автоперевод также решено отложить целиком. Неизвестным словам нельзя показывать выдуманный перевод.

Шесть старых демонстрационных занятий оставлены на главной без категорий. Они используют сессию браузера; новые занятия опираются на опубликованные материалы и аккаунт.

## Реализовано

- Аккаунты, вход, профиль и роль `Editor`. Публичная регистрация не выдаёт роль редактора. `/editor` защищён ролью; ссылка на редактор находится в профиле.
- На `/editor` сначала выбирают слово, аудиопазл, перевод фразы или книгу. Для каждого типа есть отдельная форма. Заполненный черновик можно сохранить, открыть повторно, изменить, посмотреть глазами ученика и опубликовать после подтверждения проверки текста, перевода и прав. Старые POST-маршруты создания и публикации сохранены для совместимости.
- Для аудиопазла запись обязательна, для слова необязательна, у перевода поля записи нет. Связанные слова выбираются поиском по опубликованному словарю без GUID. В тексте книги пробелы и пунктуация сохраняются; конкретное вхождение слова можно связать со словарной записью. Ручного ввода JSON в интерфейсе нет.
- Опубликованный материал редактируется через черновик новой версии. До публикации ученики видят прежнюю версию; публикация сохраняет ID и записывает историю без функции отката. Начатая попытка хранит снимок слов для сборки, ответа, записи и пояснения. При изменении книги сохраняются ID неизменённых глав и корректируется позиция чтения.
- Ученические страницы: `/audio-puzzles`, `/translate`, `/vocabulary`, `/word-practice`, `/game`, `/books`, `/progress`. `/game` — отдельная страница подбора пар; `/word-practice` содержит только повторение переводов. Для игры нужны хотя бы два сохранённых слова с разными переводами.
- В книге нажатие на слово показывает опубликованный перевод, пример и доступную запись, а также позволяет сохранить слово. Позиция чтения сохраняется в аккаунте. Неизвестные слова пока не переводятся автоматически.
- Ответы проверяются на сервере; повторная отправка не создаёт второй результат и очки. Попытки, словарь, чтение и прогресс привязаны к пользователю. JSON API расположен под `/api/v1`; адрес `/audio-puzzles` сохранён.

## Последние изменения интерфейса

В ветке `codex/design-green` новая зелёная тема стала основной: главная воспроизводит композицию зелёного образца, шапка объединена в одну строку, мобильные поиск и аккаунт находятся в раскрываемом меню, четыре раздела — в нижней панели. Декоративные иллюстрации подготовлены через ImageGen и сохранены в `wwwroot/images/green`. Название и длительность урока берутся из действующего каталога. Внутренние учебные страницы пока сохраняют прежнее оформление содержимого.

[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — основной справочник для следующих страниц; токены и общие компоненты находятся в `wwwroot/css/theme-green.css`. При изменении токенов обновлять справочник вместе с CSS. Меню управляется `wwwroot/js/nav.js`: наведение мышью на компьютере, нажатие, клавиатура и Escape.

Ниже — описание предыдущего состояния интерфейса до переноса главной.

В шапке есть выпадающие меню «Задания» и «Слова» с иконками и разделителями по примеру пользователя. На компьютере они раскрываются при наведении, на телефоне и с клавиатуры — нажатием. «Задания» содержит общий каталог, аудиопазлы и перевод фраз; «Слова» — тренировку, подбор пар и личный словарь. Одновременно открыто не больше одного меню.

Главная упрощена: категории и декоративные иллюстрации карточек убраны. В практике слов выровнена типографика вокруг Arial и сокращены отступы формы. Шапка компактнее при узком окне. Подбор пар вынесен из тренировки на `/game`. В редакторе материалы разделены на черновики и опубликованные с фильтром по типу.

## Проверка и ограничения

Новая тема проверена в headless Microsoft Edge на ширинах 360, 600, 768, 1024, 1280 и 1920 px, в том числе с увеличением всех текстовых размеров до 200%. Проверены поиск и пустой результат, запуск демонстрационного урока, меню мышью/нажатием/клавиатурой, Escape, гостевые переходы к защищённым разделам и место над нижней панелью. Авторизованный профиль и содержимое защищённых страниц в новой теме не проверены: в окружении проверки не настроено подключение с учётными данными подготовленной БД.

Стандартная сборка решения столкнулась с блокировкой DLL в `bin`; сборка с отдельным каталогом вывода прошла без ошибок. JavaScript прошёл `node --check`. Предупреждение `NU1900` связано с недоступным индексом уязвимостей. Для текущего предпросмотра используется `http://127.0.0.1:5188`; это временный локальный процесс.


Проводилась ручная проверка создания, редактирования, предпросмотра и публикации четырёх типов материалов; версий и видимости старого материала до публикации; завершения начатой попытки по снимку; повторного ответа; позиции чтения; доступа к чужим данным и запрета `/editor` без роли; ошибок файла и разметки. Страницы просматривались на широком и узком экране, проверялось отображение Ӕ/ӕ. Последняя сборка `dotnet build IronLanguage.slnx --no-restore -v:quiet` завершилась без ошибок; предупреждение `NU1900` связано с недоступным индексом уязвимостей NuGet в ограниченной сети. Изменённые JS-файлы проверялись `node --check`.

Проверенного стартового контента пока нет. Для запуска нужны 30 озвученных фраз, 50 слов и 3 коротких адаптированных текста с подтверждёнными правами. Их не следует заменять случайными или автоматически сгенерированными переводами. Тестовый скрипт с учётными данными не сохранялся.

## Где продолжать

Подготовлено UX-предложение в `UX_CONTENT.md`: три учебных раздела («Упражнения», «Мои слова», «Книги»), результаты и редактор в профиле, подбор пар внутри личного словаря, тексты страниц и состояний. Это предложение, а не реализованная навигация. В коде `Models/Lesson.cs` сейчас один пробный урок «Первые слова из «Азар!»» с четырьмя словами и шестью вопросами; старые описания шести уроков в документации не соответствуют текущему каталогу. При дальнейших изменениях сверять фактический контент и не переносить демонстрационные названия из PNG-макетов.

- `IronLanguage.Db/Entities.cs`, `AdamDbContext.cs`, `Repositories.cs`, `EditorRepository.cs` — данные и репозитории; миграции — в `IronLanguage.Db/Migrations`.
- `IronLanguage.Web/Controllers/EditorController.cs` и `EditorWorkflowController.cs` — совместимые старые POST-маршруты и новый workflow редактора.
- `IronLanguage.Web/Controllers/LearningApiController.cs` и `Services/LearningService.cs` — ученический API и проверка занятий.
- `IronLanguage.Web/Views/Shared/_Layout.cshtml`, `wwwroot/css/features.css`, `wwwroot/js/nav.js` — шапка и меню.
- `IronLanguage.Web/Views/Practice/WordPractice.cshtml`, `Game.cshtml`, `wwwroot/js/word-practice.js`, `game.js` — повторение и отдельная игра.
- `README.md` — настройка PostgreSQL, миграций и роли редактора. Секреты в репозитории не хранить.

Во время разработки локальный сайт запускался на `http://127.0.0.1:58322` с PostgreSQL на порту `58321`. Это временное окружение, а не публикация; процессы могут остановиться после закрытия сессии. На момент записи файлы проекта отображались в Git как untracked — не удалять их при очистке.
