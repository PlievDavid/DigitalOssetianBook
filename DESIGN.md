# Адам — набросок приложения

Файл `language-app-sketch.svg`: три мобильных экрана 384 × 784, редактируемые векторные элементы. Это локальный макет для импорта, а не созданный через Figma файл. Шрифт Arial — временный, перед Flutter-реализацией подобрать и проверить шрифт с осетинскими символами Ӕ/ӕ.

## Сценарий

1. Уроки: дневная цель, продолжение занятия, список уроков, нижняя навигация.
2. Упражнение: прогресс, слово с озвучиванием, выбор ответа, проверка. Зелёная рамка означает выбор, а не правильность до проверки. После проверки в реализации показать текст результата и кнопку следующего задания. На макете показано третье задание из восьми, затем отдельно финальный результат всего урока.
3. Результат: верные ответы, время, повторение ошибки, возврат к урокам.

## Будущие Flutter-компоненты

- `LessonHomeScreen`, `ExerciseScreen`, `LessonResultScreen`.
- `DailyGoalCard`, `ContinueLessonCard`, `LessonTile`.
- `ExerciseProgress`, `AudioWordCard`, `AnswerOption`, `PrimaryButton`, `ResultStatCard`.
- `NavigationBar` для разделов «Уроки», «Слова», «Профиль»; последние два экрана вне этого наброска.

## Обязательная адаптивность: телефон, планшет, компьютер

Компьютер — полноценная целевая платформа интерфейса. Отдельное решение о выпуске установочного приложения для Windows/macOS пока не принято; настольный браузер входит в требования. Файл `language-app-desktop.svg` показывает настольные варианты уроков и упражнения при ширине 1280.

Начальные пороги определяются доступной логической шириной окна, а не типом устройства; уточнить при проверке контента и увеличенного текста:

| Ширина | Навигация | Уроки | Упражнение и результат |
| --- | --- | --- | --- |
| < 600 | Нижняя NavigationBar | Одна колонка, отступы 16–24 | Одна колонка, кнопка после содержимого либо в безопасной нижней области без перекрытий |
| 600–1023 | Компактная NavigationRail | Одна или две колонки по доступной ширине | Центрированная колонка до 640 |
| ≥ 1024 | Боковая панель шириной около 220 | Основная колонка и панель дневного прогресса; суммарная ширина до 1120 | Центрированная колонка до 640; в режиме занятия общая навигация скрыта |

Flutter: `LayoutBuilder` для выбора компоновки, `ConstrainedBox` для ограничения ширины, `Expanded`/`Wrap` для гибкого распределения места. Данные, состояние занятия и компоненты общие между компоновками. При изменении размера окна сохранять выбранный ответ и прогресс.

Настольное управление: видимый фокус, логичный порядок Tab, выбор ответа с клавиатуры, Enter/Space на сфокусированных кнопках, понятные состояния наведения. Ни одна функция не доступна только при наведении. Масштабирование текста не должно скрывать кнопки; вертикальная прокрутка допустима, горизонтальная для основного интерфейса — нет.

При реализации проверить ширины 360, 600, 768, 1024, 1280 и 1920, узкое настольное окно, текст 200%, клавиатуру и изменение размера посреди занятия. Это критерии будущей реализации, SVG сам по себе не является работающим адаптивным интерфейсом.

## Визуальные параметры

- Фон: #FAFBF7; текст и основные кнопки: #203F34; вторичный текст: #69756D.
- Мягкая заливка: #EDF1E7; акцент: #DCECAF; рамки: #DEE4D9.
- Боковые отступы 24; основные интервалы 8/12/16/24; радиусы 14–20; кнопки 54 по высоте.
- В реализации использовать SafeArea, прокрутку и адаптивную ширину, не абсолютные координаты SVG. Проверить увеличение текста и маленькие экраны.

## Перед реализацией

Макет содержит демонстрационные значения, а не реальные результаты пользователя. Переводы и аудио проверить с редактором осетинского языка. Нужны состояния правильного/ошибочного ответа, загрузки, ошибки сети, отсутствующего аудио и пустого прогресса.

SVG можно импортировать в Figma через Place image либо перетаскиванием. Он не содержит Auto Layout, библиотечных компонентов и связей интерактивного прототипа; их следует создать при переносе в полноценный Figma-дизайн.
